# 存股 App

手機用的存股記帳＋損益／報酬率／年化(XIRR)看板。計算邏輯對照原本的 Excel「存股表格_V2」，數字一致。

## 檔案
- `index.html` — App 本體（單一檔案，直接能用）
- `prices.json` — 收盤價（由下面的自動流程每天更新）
- `scripts/fetch-prices.js` — 抓官方收盤價的程式
- `.github/workflows/update-prices.yml` — 每個交易日下午自動跑

## 隱私（重點）
- **你的交易紀錄只存在手機瀏覽器裡（localStorage），永遠不會上傳、不上 GitHub。**
- GitHub 上只有「空的 App 程式」和「全市場公開收盤價」，看不到你買了什麼。
- 資料只在這支手機 → 請用 App 內「設定 → 匯出備份」定期備份（存 Google 雲端或傳給自己）。換手機用「匯入」還原。

## 先馬上用（不碰 GitHub 也行）
把整個資料夾傳到手機，用瀏覽器打開 `index.html` 就能用，價格手動填。

## 開自動抓價（GitHub，一次性設定）
1. 到 github.com 建一個 repo（名字隨意，例如 `stock`）。
2. 把這個資料夾整包上傳（含 `.github` 資料夾）。
3. repo → **Settings → Pages** → Source 選 `main` 分支 `/ (root)` → 存檔。過一下會給你一個網址。
4. repo → **Actions** 分頁 → 若問要不要啟用，按啟用 → 進「更新台股收盤價」→ 按 **Run workflow** 先手動跑一次，確認 `prices.json` 有被更新。
5. 手機用步驟 3 的網址打開，加到主畫面。之後每個交易日下午 4 點會自動更新收盤價。

## 說明
- 抓的是**官方收盤價**，交易日下午更新一次，非盤中即時（存股看收盤即可）。
- 週末、休市日維持上一個收盤價，App 會顯示價格日期。
- 成本用加權平均法；股利／借券折抵現有持股成本；年化用 XIRR。

## 小提醒
- GitHub 免費排程若 repo 60 天沒任何動靜可能被自動停用，偶爾進去按一下 Run workflow 即可喚醒。
- 交易紀錄 Row1（0050）的手續費目前填 0，記得照券商對帳單補上實際金額。
